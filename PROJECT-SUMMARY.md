# Project Summary

## Title

Secure VPC Web Architecture on AWS

## Objective

To design and deploy a highly available web application infrastructure using AWS networking and compute services.

## AWS Services Used

* Amazon VPC
* Public Subnets
* Route Tables
* Internet Gateway
* Network ACLs
* Security Groups
* Application Load Balancer
* Target Groups
* Launch Templates
* Auto Scaling Groups
* Amazon EC2

## Key Features

* High Availability across multiple Availability Zones
* Load Balancing using Application Load Balancer
* Automatic instance replacement using Auto Scaling
* Health Checks using Target Groups
* Secure traffic flow using Security Groups and NACLs

## Challenges Solved

1. Target Group health check failures
2. Security Group configuration issues
3. NACL configuration and ephemeral ports
4. Auto Scaling replacement instance troubleshooting
5. Application startup automation using User Data

## Outcome

Successfully deployed a fault-tolerant web application architecture and validated Auto Scaling, health checks, and network security concepts.
